# FairyTail – Sharing Hearts

A responsive, animated landing page concept for a volunteering/charity initiative, built with vanilla HTML, CSS and JavaScript.

## Features

- Animated page preloader
- Responsive sidebar navigation with a hamburger menu for mobile
- Home / About Us / Team / Services / Contact sections
- Social media links (Font Awesome icons)
- Custom typography via Google Fonts (Baloo Da 2, Josefin Slab, Muli)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Run locally

1. `git clone https://github.com/Ranjith-13/fairytail.git`
2. `cd fairytail`
3. Open `ft web.html` in your browser.
